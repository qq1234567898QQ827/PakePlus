小球紧贴斜面

重力 mg 9.80 N

临界条件推导

当 N = 0 时，达到临界状态

设绳子与水平方向夹角为 α

竖直方向：T·sinα = mg

水平方向：T·cosα = ma₀

两式相除得：tanα = g/a₀

临界时 α = θ，故 a₀ = g·cotθ

临界加速度：a₀ = g·cot30° ≈ 16.97 m/s²

💡 物理规律总结

阶段一：a < a₀（小球在斜面上）

支持力 N 随加速度增大而减小，拉力 T 随加速度增大而增大，绳子始终与斜面平行。

T = m(g sinθ + a cosθ)，N = m(g cosθ - a sinθ)

阶段二：a ≥ a₀（小球离开斜面）

支持力 N = 0，绳子与水平方向夹角 α 随加速度增大而减小，绳子逐渐趋于水平。
